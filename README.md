# Card Master 3D

使用 React、TypeScript 与 Three.js 开发的卡牌战斗游戏：实体卡牌与立体技能特效，提供深渊挑战、全屏 3D 单人战役、世界树迷宫、本地选卡对战，以及抽卡、组卡、商店和融合；新增天梯大厅与本地排行榜。

**当前版本：v3.0 · 深渊模式与单人战役重做**（2026-10-12）

[游戏规则总文档](docs/GAME_RULES.md) · [Trait 对照表](docs/TRAIT_REFERENCE.md) · [施工清单](docs/CONSTRUCTION_CHECKLIST.md)

## v3.0 主要更新

- **深渊模式**：独立挑战流程，三套起始卡组、三心生命、逐层敌人、正负绑定契约、战后培养与招募；支持继续进度、已知特性和游玩历史。大厅采用黑洞云旋与闪电演出，备战和实战使用最高画质的全新深渊盘面。
- **单人战役重做**：从菜单式选关升级为全屏 3D 多岛世界。人界、魔域、圣域与月之都采用各自地形和建筑；可移动视角、自动聚焦区域，关卡旗标落在对应地景，详情按选中状态弹出。地形与大型模型通过 Worker、分批加载和远近细节组织。
- **天梯与排行榜**：新增独立天梯卡组、九档段位、积分预览、旋转水晶与首次达标奖励；主界面和天梯共用天梯榜 / 收藏榜浮层。当前排行榜为本地演示，单人及 2v2 匹配尚未开放。
- **世界树迷宫优化**：地块图标与布局更新，节点提示栏手动开关，补给货架免费刷新、3–5 张商品与优惠；新增每百次首次探索的活动卡保底，以及每周一次清空额度，账本与地图一并保存。

此外加入剧情 / 签到奖励、三套普通卡组与专用天梯卡组、统一数字字体，并完善丰收、大理石厅、太阳系、冰原与深渊等战场。

## 游戏特点

- **出牌与上场分开决策**：出牌决定中长期节奏，成熟卡的部署时机与插入位置决定眼前对位。
- **实体卡牌与动态数值**：卡牌有厚度、稀有度边缘和闪卡效果，ATK / HP / CD 独立显示；技能、状态与死亡采用立体演出。
- **共享卡牌介绍**：战斗、卡组、抽卡、商店和选卡等界面，悬停卡面即可在指针附近查看数值与特性功能；点击进入详细检视。
- **规则与表现分离**：`src/domain/` 不依赖 React、Three.js 或 DOM；引擎根据命令产生事件，界面负责播放。相同种子与命令序列可复现规则结果。
- **本地账号与存档**：登录 / 注册、账号独立进度；藏品、牌组、货币、进度和设置统一保存，支持 JSON 导入与导出。
- **八种战斗场地**：锦标赛、未来、火山、大理石厅、太阳系、丰收、冰原、深渊；包含实体景观、动态材质、天气与光效，深渊固定最高画质，其它场地支持画质调整。

## 快速开始

需要 **Node.js >= 22.12.0**。

```bash
npm install
npm run dev
```

开发地址：`http://127.0.0.1:5173`。

进入后会播放星空与巨型卡牌盘面的 3D 开场，提示出现后点击任意位置登录。初始账号 / 密码：**`admin` / `admin`**；也可注册独立本地账号。`admin` 延续原存档，账号与进度保存于当前浏览器站点，详见 [登录系统](docs/LOGIN_SYSTEM.md)。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run test` | Vitest 单元测试 |
| `npx playwright test` | Playwright 浏览器用例 |
| `npm run build` | 类型检查与生产构建 |
| `npm run preview` | 本地预览生产构建 |

开发开关：`?day=YYYYMMDD` 固定存档时钟，`?failsave=1` 模拟存档写入失败，`?audio=0` 强制静音，`?audio=1` 尝试解锁音频。

## 战斗规则（v2.0 起）

默认每方本体 20 HP、牌组最多 12 张，开局抽 3 张；等待区 8 槽，战斗区 5 槽。

1. **随机先后手**：开局随机决定先行动的一方，后手额外获得一张冷却牌。
2. **普通出牌与跳过**：每个己方回合最多打出一张普通牌到等待区；不打普通牌而结束行动，可获得一张冷却牌。部署和使用冷却牌不影响该奖励。
3. **冷却牌**：指定己方等待区中仍在冷却的卡，令 CD−1，最低为 0；用后消耗，不占普通出牌额度。仅能在己方主场操作阶段使用。
4. **成熟后手动上场**：每次回合交棒，双方等待区的 CD 都减 1。CD 为 0 时出现金边，卡牌保留在等待区，玩家自行决定是否部署。
5. **抢先选择**：客场有成熟卡时，主场可选择先完成行动和整排攻击，或先让客场部署。客场只部署成熟卡或放弃部署，没有额外抽牌、普通出牌或整排攻击；上场技能立即生效。
6. **自由插队**：每次部署可头插、尾插或插入现有队列中间，原卡保持相对顺序。每轮可逐张部署多张，最多占满五槽；不能留空槽或挤出原卡。

操作时拖动金边等待卡，卡牌会放大并预览后方卡牌让位；松手到合法位置完成部署，放回等待区或按 Esc 取消。也可点击成熟卡，再点击高亮战斗槽。

当前 AI 使用基础规则策略：优先短 CD 普通牌，有合法目标就使用冷却牌，随机抢先、随机插入位置，有空位时部署成熟卡。尚未加入难度训练、搜索或学习模型。

完整时序、胜负条件、状态期限、死亡与卡牌重置规则见 [游戏规则总文档](docs/GAME_RULES.md)。

菜单背景使用视差移动与背景图交叉淡入淡出。大厅采用原画底纹与金边按钮、底部图标导航和带版本号的立体标题，左侧集中邮件、好友、公告及外部链接入口；待开放或未配置链接的入口会显示提示。战斗中可拖动旋转视角、滚轮缩放，战斗设置可随时调整。测试用增加资源按钮位于默认收起的 admin 导航栏，展开后可发放金币与水晶。

台面顺序为 **锦标赛、未来、火山、大理石厅、太阳系、丰收、冰原、深渊**。锦标赛保留木质牌桌和反光大理石地面；未来使用环绕中央台面的悬浮科技立方体，以及绿色 / 黄色牌堆计数和红色弃牌计数；大理石厅采用宽大希腊神庙、整块白色台面与密集天然纹路，中央喷泉沿双方分隔水槽向左右出水，经桌边下降汇流后落入低位水池；火山使用六角岩台、起伏玄武岩柱、流动熔岩与上升余烬；太阳系保留深色盘面与冷光，加入星空、太阳、八大行星、轨道及陨石带，盘面悬浮于地球与火星轨道之间；丰收使用八边形倒角石台、十个双层战斗基座、中央峡谷与连接双方边缘中心的蜿蜒小路，周围布置花草和摇曳麦田，保留暖色浮尘和光效；冰原采用整面冰层、覆雪边缘与错落冰冠，复用技能冰锥、霜纹冷雾和飘雪演出；深渊采用破裂黑曜石祭台、中央紫色裂隙、立体云旋、悬浮残骸与间歇闪电，备战和实战自动使用，固定最高画质。已移除草原、祖母绿、象牙与乌木、霓虹网格，旧设置自动回退到默认主题。

音效通过 WebAudio 合成，涵盖起手、命中、死亡、抽卡与融合，首次用户操作后解锁；设置中的主音量会保存。

## 卡牌制作与素材

卡牌数据与卡面由同级工具仓库 [`cardmaker`](../cardmaker) 制作：选原画、裁剪构图、填写数值与特性，然后导出到本项目。主要输出为 `src/data/cards.json`、`src/data/assets.manifest.json`、`public/assets/card/{thumbnail,battle,detail}/` 与原画。手工调整这些文件时，需要留意后续工具导出可能覆盖相应内容。

运行所需派生纹理随仓库提交，本地参考工程 `assets-library/` 不入库。素材与移植代码的来源、许可和文件对应关系见 [assets-sources.json](assets-sources.json)。

- 战桌、材质、光照与天气系统使用 [Chessboard-three.js](https://github.com/ibra-kdbra/Chessboard-three.js) 的部分代码（MIT）。
- 部分技能 Shader 来自 [LinearAbiltyCastingThreeJS](https://github.com/achrefelouafi/LinearAbiltyCastingThreeJS)（MIT），火、冰、雷等技能按本项目战场尺寸与卡面位置调整。
- 炮击、爆裂与远射等效果使用 [three.quarks](https://github.com/Alchemist0823/three.quarks) 粒子系统；具体实现与素材登记见 [战斗特效文档](docs/BATTLE_VFX.md)。
