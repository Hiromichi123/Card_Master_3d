# 深渊第一大轮平衡

- 第一大轮指 floor=1，即 1-1 至 1-10。仅常规难度敌人取消全局增益；高难（1-3/1-6/1-9）与噩梦Boss（1-10）保留。
- 第二大轮及之后，全部敌人继续按原规则携带并缩放全局特性。卡牌原生技能、敌方卡组和本体成长不变。
- 第一大轮三组正负契约使用现有绿→蓝→紫→金→红等级比较。正面稀有度严格高于绑定负面时，整组候选的原权重乘4；其余保持1倍。此倍率提高概率，不等于固定概率或保底，仍保留正面低于／等于负面的组合。
- 第二大轮起倍率统一为1，恢复原有稀有度权重与去重抽样，不再受前期扶持影响。
- 已存档契约不重新抽取；第一大轮普通关已有的旧敌方全局增益在战斗编译、召唤、特性展示及已知特性发现时统一禁用，新生成关卡保存零修正“无全局特性”。旧档保持可读，无需重开。
- 游戏内“规则讲解 → 契约与特性等级”同步展示本规则。
