- 移除特效实验台的「飞行提示」。带飞行特性的战斗卡上场后升高 0.95 世界单位，槽位下方播放一次白色圆阵；顺位整理与受击不重复圆阵。技能命中坐标继续使用地面位置。
- 普攻不产生球体、粒子、命中圆圈或镜头震动。出手卡在 0.12 秒内加速前冲，再用 0.18 秒返回；前冲距离最多 0.5，并根据卡牌深度保留对位间隙。反击共用这套移动。
