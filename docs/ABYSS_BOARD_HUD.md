# 深渊盘面战斗数值

- 深渊双方牌堆复用未来盘面的盘面计数：绿色剩余数、黄色斜线与初始总数；双方弃牌堆只显示红色数量。统一采用默认 Georgia 数字字体。
- 双方各自在牌堆左侧对应的盘面半区开一条宽约0.147、长5.4的浅槽，两端为半圆，只保留靠近盘面的暗色槽底，移除紫色外框和刻度。己方（青绿）与敌方（玫红）分处玩家和对手半区；扣血时空缺从盘面中央端开始，液面分别退向双方外缘。
- 液体按当前生命／本局本体生命上限填充，受击或恢复时平滑变化；槽下方显示当前／上限数字。数据来自战斗表现快照，在伤害命中节点更新，不提前泄露规则结算结果。
- 减少动态设置停止液体流动并立即更新液位。液位为零时隐藏液体，数字仍显示。
- 深渊战斗移除原顶部双方信息框；左上新增当前层数标题，“本战特性”展开入口位于标题下方。其他盘面保留原 HUD。
- 槽体属于持续存在的深渊盘面；液体与数值属于当前战斗层，战后清场时随战斗层退出，避免重载背景。

起始选组修复：卡组按钮按实际牌组下边缘定位；提交时读取最新存档版本并保留阶段、局身份校验，失败优先显示具体存档原因，避免通用提示掩盖真实错误。

开局选组按钮已恢复独立屏幕层之前的 Drei Html 默认挂载方式和三维锚点，不指定 portal，不添加视口引用或额外投影控制器。按钮一缺失的根因尚未确认；不据此改动下侧按钮布局。

生命液体采用纯红／纯绿通道渐变，移除高亮边缘和模拟反光；槽底采用无金属、粗糙度1、无环境反射材质。

战斗 HUD 保留原有顶部与底部两个 flex 容器。深渊只隐藏顶部双方信息内容，不删除顶部容器，避免 space-between 失去顶部占位后把右侧操作列移到上方。

生命槽进一步缩至宽0.12，液体基准宽0.064；细分液体长边，用沿长度传播的波峰和整体呼吸改变实际宽度，波动保持在槽内。内部同色丝流、核心光和受击波纹不使用白色反射。受击液位以约0.72秒平滑下降、回血约0.48秒回升；再次命中从当前显示液位衔接，数字逐整数跟随下降，仅数字变化时重绘已有贴图。
