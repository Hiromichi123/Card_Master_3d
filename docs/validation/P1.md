### 3.2 依赖安装

`npm install` 一次通过，143 个包，无引擎警告。`package.json` 中的版本与
`docs/VERSIONS.md` 完全一致，全部精确锁定（不含 `^`）。

**TypeScript 7 的一处实际差异**（已踩到并记录）：TS 7 **移除了 `baseUrl`**，
`paths` 必须写相对路径。原配置报 `TS5102`，改为
`"paths": { "@/*": ["./src/*"] }` 后通过。`docs/VERSIONS.md` 中预告的
「TS 7 可能有兼容性差异」得到了第一个实例，但**不需要回退到 6.x**。
