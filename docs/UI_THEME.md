# UI 统一主题

`src/ui/theme.css` 是框、按钮、滚轮台、货架、输入控件与滚动条的统一外观入口。
`src/main.tsx` 加载它，覆盖所有页面；卡面、稀有度材质、3D 画布和场景背景继续使用自己的表现。

## 调整颜色与流动

在主题文件的 `:root` 中统一调整：

| 变量 | 用途 |
| --- | --- |
| `--ui-default` | 半透明默认填充；不运动时仍完整显示 |
| `--ui-flow-cool` / `--ui-flow-warm` / `--ui-flow-violet` | 冷色、金色与介绍框的辅助流光颜色 |
| `--ui-gold` / `--ui-gold-bright` / `--ui-gold-dim` | 金边、选中亮边、暗部金色 |
| `--ui-edge` / `--ui-edge-inner` | 外框与内装饰线 |
| `--ui-flow-duration` | 填充流动周期，默认 22 秒，货架为 28 秒 |
| `--ui-text` / `--ui-text-dim` | 正文与次级文字 |
| `--ui-radius-panel` / `--ui-radius-control` | 面板与控件倒角尺寸 |

填充使用低对比径向渐变缓慢移动，不移动文本、尺寸或整个组件。主按钮与选中项更亮，悬停增加金边光泽；禁用控件停止流动并降低亮度。错误反馈、双方颜色和卡牌稀有度保持各自语义。

## 新组件接入

- 面板添加 `ui-panel`，动作控件使用原生 `button` 或添加 `ui-control`。
- 重点动作添加 `ui-control--primary`，选中项添加 `ui-selected`，或使用 `aria-pressed` / `aria-selected`。
- 局部需要不同填色时覆盖 `--ui-default`、`--ui-flow-cool`、`--ui-flow-warm`，不要另写整套边框和背景。
- 卡牌、海报和地图格的图片点击区域不套按钮背景；新增同类区域应加入主题文件的排除选择器。

各页面已有类名通过主题文件的适配选择器统一接入。全局、卡组、融合和本地选卡的布局样式归于 `legacy` CSS 层，统一外观位于更高优先级的 `theme` 层，避免页面选择器相互争夺颜色。

游戏“静止”设置通过根节点 `data-ui-motion` 暂停 UI 流光；系统减少动态效果设置同样生效。抽卡过渡、翻牌、战斗动作与稀有度圆球不受主题暂停规则影响。

本次仅编辑源码与文档，未运行实例、测试、类型检查、构建或截图检查。

## 主界面入口

`src/scenes/HubScene.tsx` 维护三层玩法入口与底部七项导航的名称、路由和颜色。
`src/ui/hubMenu.css` 在 `hub` 层复用金边主题，加入按钮侧面阴影、悬停弹起、放大与呼吸高亮。
开始战斗为蓝色横向渐变，今日商城为青绿，活动模式为橙红，活动商店为紫色，抽卡为金红。
底部“商城”保留未开放提示，与“今日商城”的现有商店区分；排行榜、统计数据也暂未开放。

全部入口使用 `HubLogoLayer.tsx` 的同一张透明 Three.js 画布：交叉几何剑、晶匣、晶钻、卡牌叠层、打开的书、交错祭坛环、齿轮、沙漏等。
模型对齐各按钮内的 DOM 占位，在悬停或键盘聚焦时缓慢旋转；无选中项且过渡结束后停止请求画面。
设置为“静止”或系统启用减少动态效果时，暂停旋转、呼吸与弹起。重置存档保留确认。

### 手绘布局比例

主界面以实际可视区域为布局基准，标题居中偏上；三层按钮组位于右上区域（左侧约 54%、顶部约 21.5%、宽度约 26.5%）。第三层使用三张等宽、接近方形的按钮。
海报位于按钮组下方（左侧约 51%、顶部约 58%），恢复旧舞台 35% × 30% 对应的 28:15 宽高比；宽度不超过画面 35%，高度不超过 32%，左半侧保留背景展示。
底部七项导航居中横跨约 80% 画面，按钮厚度、图标和文字相较前一版增大 30%，图标与文字横向排列；底部略沉入画面边界，图标和文字仍完整可见，悬停时浮起。小尺寸入口收起副说明，完整说明仍可悬停查看。
尺寸和间距按比例整理，不按手绘像素逐点复刻；功能、配色和悬停效果保持不变。

上方七个按钮与海报同步上移画面高度的 3%，两者之间的间距保持不变。

装饰用 `HubLogoLayer` 的 `Canvas` 必须显式传入 `style={{ pointerEvents: 'none' }}`。React Three Fiber 默认在容器写入内联 `pointer-events: auto`，单靠外层 CSS 无法覆盖，会挡住整屏按钮的点击与悬停。

## 工坊调整

材料区域改名“牌库”，左边界向屏幕左侧扩展，保持右边界不变并改为每行六列。祭坛观察方向取消横向偏角，使用正前方俯视。
`fusionSpinAngle` 统一驱动融合时的旋转：加速、减速、停止，完成后不再空闲旋转。结果卡不随台面旋转，保持面向观察者；静止设置关闭旋转演出。
法阵的黑底贴图同时作为 alphaMap，并剔除透明像素，隐藏其方形托盘轮廓，保留发光圆环与下方实体祭坛。

## 基础按钮金线倒角

`src/ui/buttons.css` 统一维护按钮的八边倒角、渐变金边和两条内侧装饰金线，沿用介绍框的配色。
边框与填充由两个不接收指针的伪元素绘制，按钮本体不裁剪，因此抽卡价格标签和已有点击范围保留。
悬停、聚焦和选中时金边更亮；禁用时变暗并停止流动。普通按钮用 `--ui-fill`，主界面的彩色按钮用 `--ui-control-fill`，倒角可覆盖 `--ui-control-bevel`。
CSS 层顺序为 `control-defaults → legacy → theme → hub → controls`。默认相对定位位于最底层，原有绝对定位按钮保持位置。

背景衔接仍只混合图片，图片加载完成后才开始过渡，完成后才记住新背景；快速切换页面不提前把未显示的新图当作旧图。鼠标阻尼、背景位移与现有静止设置不调整。

## 登录入口

`src/ui/login.css` 只作用于新登录页和进入大厅的裁剪层。标题使用金属金色渐变与柔和高光，中央表单使用公共 `ui-panel` 流动填充、金线双层边框和角部装饰；登录 / 注册沿用公共倒角按钮。
表单进入与离开是流程动画，不随装饰流光暂停。原有大厅与菜单的鼠标阻尼设置不调整。
登录成功后的裁剪边缘由 Three.js 中的实体卡牌投影逐帧给出，裁剪内容为提前挂载的真实大厅；直到铺满视野前，大厅保持 inert，防止按钮穿透点击。

## 大厅材质按钮与侧边入口

右上七项按钮采用低饱和金属配色、真实卡牌原画底纹、静态 SVG 颗粒和细拉丝；外边框仍由公共金线倒角组件绘制，悬停只轻微露出底纹，不用整块鲜艳填色。布局与路由沿用原设置。
`HubScene` 的 `MAIN_ART` 集中指定按钮插画，卡牌原画缺失时回退 battle 卡面，装饰层均不接收指针。

左侧 `HubSideRail` 提供邮件、好友、公告、QQ、Steam、X、支持开发者，使用统一描边 SVG 图标。鼠标悬停或键盘聚焦显示名称；前三项当前显示未开放 / 暂无公告提示。
外部地址集中维护于 `src/data/hub-links.json`，键为 `qq`、`steam`、`x`、`support`，未提供时留 `null` 并显示未配置提示。配置后采用新窗口链接与 `noopener noreferrer`；不填写猜测的社区或付款页面。

## 标题、共享原画按钮与 admin 导航栏

`HubWordmark` 将大厅标题组合为立体金属字面、阴影厚度、轻微起伏与字面光泽，后缀为 3D 和 `package.json` 的版本号；静止及系统减少动态时暂停装饰动画。
`MenuChrome.title` 接受 ReactNode，其它菜单继续使用原文字标题。

`ArtButtonSurface` / `artButtons.css` 集中维护原画底纹、颗粒、拉丝和雕刻边线，应用到大厅右上、底部导航，以及抽卡单抽 / 十连 / 返回 / 完成操作 / 跳过和卡池滚轮选项。抽卡操作与选中的卡池使用金色高亮，底纹取该卡池高稀有展示卡的原画。装饰层不接收指针，价格标签保留在按钮外侧。

顶部改名 admin 导航栏，刷新后默认收起；展开后显示路由、测试资源、当前账号与性能开关。原抽卡 +50000 金币 / 水晶迁入 `AdminResources`，在所有页面可用，沿用原子存档事务与繁忙防重复提交。名称表示开发导航栏，当前未增加账号权限限制。
抽卡主页面已移除资源入口，不改抽卡概率、扣费或舞台演出。
