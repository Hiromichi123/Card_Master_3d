# 新 trait 调整（2026-10-07）

## 规则

- 死亡爆裂对敌方全体存活战斗单位发出炮击，无敌方单位时延续已有本体落点。原地中体积爆炸只播放一次，多个敌方落点分别生成大体积炮击。
- 即死n：随机一个存活敌方单位，黑色 Voltaic Snare 诅咒命中后直接清空 HP 并进入死亡处理。n 保留为等级参数，不改变必杀判定；正常死亡技能、不死/复活流程仍可处理离场。
- 法术反弹：持有者在战斗区存活时立即保护己方，拦截敌方元素、炮击、诅咒、延迟、即死及死亡爆裂等进攻法术，把整个施法反射回去：单体法术返回原施法者，群体法术返回施法方全体。反射只执行一次，不因双方都有反弹而循环。沉默按既有规则禁用被动。
- 物理伤害、远射、贯穿动作及普通反击不作为法术反弹对象。
- 闪避赋予n：完整复用破甲的动作、粒子和时序，仅改为金色，传给随机友方（有其它友方时优先其它，无其它时可给自己），获得闪避n直到离场。重复赋予保留最高等级，和原有闪避等级取较高者；离场后清除，复活/再次上场不保留上一次赠予。
- 伤害n：随机敌方单位受到一次 n 点普通攻击；群体伤害n对敌方全体各造成一次。使用普通前冲、HP 闪烁与快速整数扣血，正常结算防御、圣盾、闪避、反击、飞行改道和攻击后技能。
- 贯穿n：独立对敌方本体造成 n 点伤害，金色直线光尾，无爆炸，不再修改后续普通攻击目标。远射仍保留此前的普通攻击直击本体属性。
- 即死的 HP 直接清零，不播放逐整数倒计数；其它伤害保留原有快速回落。

新增规则与三张卡牌的覆盖在 `withModernTraits`，原始导入 JSON 保留作旧项目快照；实验台已同步新按钮与对应卡牌。

## 斩击与剑舞（2026-10-07）

- 原始 `new.js` 保留。其反向椭圆弧、渐细尾迹、白色刀芯与随刃火花适配为 `SlashSkillVisuals.ts`，使用现有特效时间轴，不创建第二个场景、渲染器或自动播放定时器。
- 斩击n：攻击前对当前对位存活战斗单位造成 n 点技能伤害，应用原稿的两道交叉刀光；按已有技能伤害路径结算圣盾、法术反弹等。对位空槽不改打本体。
- 群体斩击n：对全部敌方存活战斗单位各造成 n 点技能伤害，每个目标播放两道交叉刀光；兼容 `群体斩n击` 的数字写法。
- 剑舞n：对当前对位直接扣除 n HP，六段交错、多方向、略有倾斜的圆弧斩击；无视飞行、防御、闪避、免疫、圣盾及法术反弹，不触发受击反击。对位空槽不改打本体。
- 群体剑舞n：敌方全部存活战斗单位各直接扣除 n HP，各播放多段剑舞；动画段数不乘算伤害。
- 真伤记作 `trueDamage`，绕过减伤钩子；HP 仍快速逐整数回落，死亡、不死/复活与死亡爆裂保持原有离场流程。命中时间由统一斩击时序配置提供，支持现有速度与全局耗时倍数。

## 献祭、斩杀与传送（2026-10-07）

- 新增 OWN_TURN：部署完成后、当前方整排攻击前，每张存活、未被沉默的在场卡触发一次。献祭与传送使用此时机，不在每次物理攻击或敌方部署时重复触发。
- 献祭n：总吸取量至多 n，随机从其它在场友方补足，按缺失 HP 与友方现有 HP 截断，满血或无来源时完全跳过。共享自身生命的分身不作来源，其它共享组只抽取一次。可以抽死友方，实际吸取量先恢复自身，再走正常死亡处理。
- 每段献祭用 LifeTransferred 显式记录来源、受益者与实际数值；套用吸血动画，从来源回流自身，不播放错误的自吸动画。
- 斩杀：仅己方回合攻击前，严格检查对位 HP < 自身 HP，触发直接击杀与即刻离场处理，套用深红色六段剑舞。兼容旧字符串斩杀3，但不将 3 作为阈值。死亡系 trait 继续按已有流程处理。
- 传送：每个自身回合随机重排敌方存活战斗单位，保持空槽位置；更新真实 slotIndex 并用 FormationShuffled 事件同步显示排列。少于两张时跳过，洗牌碰巧未改变顺序时使用一次非零旋转避免无动作。作为敌方阵容法术，可被法术反弹返回施法方。

## 群体贯穿、临点坍缩与不屈（2026-10-07）

- 群体贯穿n按用户补充定义：五条平行金色光线，统一朝敌方本体，每条单独造成 n 点伤害；实际伤害受本体剩余 HP 限制，不打战斗卡。没有因敌方卡数减少而减少光线数量。
- 临点坍缩：实际卡对卡普攻经过防御、圣盾、闪避后，使用“本次剩余攻击伤害 − 对位命中前 HP”计算非负溢出；溢出直接扣除自己 HP，自己卡面播放红色斩击。独立的伤害n普通攻击也使用同一命中原语；远射、空槽和飞行改道的本体攻击不触发，技能伤害不触发。返伤在普通受击后的反击与攻击后恢复之前结算，只触发一次。
- 不屈共享在状态组上：首次正 HP 变成 0 时启动，0 HP 卡仍可行动、施法、受击和占位；到下一个自身回合的行动整排完成后强制离场。若在自身回合中被打到 0，当前回合剩余行动仍可继续，下一次自身回合再完整行动一次。重复致命伤害或治疗不刷新期限。
- 真伤、即死、斩杀、献祭、自伤均通过同一 HP 事件截获不屈；期满后再执行正常死亡、不死/复活和死亡爆裂。每次部署生命周期至多触发一次，分身共享状态，重新部署时重置。到期复活/回手的主实例保留原有目的区域。
- 不屈的显示事件与规则事件分离：卡面挂持续 Shader 遮罩，鲜红亮边向卡牌外溢出，中部暗红覆盖；随卡牌前冲、移动、飞行和翻面一起变换。跳过/取消演出时随显示状态同步。
- 0 HP 自毁法术卡上场时使用短暂部署施法标记，完成主动技能后自毁移出，避免新群体贯穿被 0 HP 行动检查挡下。

## 无额外动画的特性：对空、群体禁飞、狂暴、攻城（2026-10-08）

## 隐匿、先攻、吞噬、至高之作、先锋与必杀（2026-10-08）

- 隐匿通过实例标记消费首次普通攻击，进入战斗区时重置；先选择实际先锋承受者，再消费其隐匿。只在普通卡对卡管线生效，技能伤害和打本体不会消费，规避后不再次抽取闪避或启动减伤动画。
- 先攻在每次选择下一行动单位时优先选先攻组，组内按现有槽位顺序，普通组同样保序。用已行动实例集合防止重复行动；新创建的在场单位可在本回合剩余调度中行动，槽位和对位不改变。
