# 自毁一次性卡牌（2026-10-07）

- 自毁在上场阶段触发，部署管线先执行其上场技能与主动技能，再最后结算自毁。不受当前行动方影响。
- 重复技能保留原始次数；自毁在 trait 列表中的位置不影响其它效果执行。未实现的技能仍不补造机制。
- ATK 大于 0 的一次性卡牌在部署时完成一击；ATK 为 0 的技能卡不产生普通攻击。
- 技能与有效攻击结束后生命归零，立即进入死亡处理并释放槽位，不再等下一次攻击回合。
- 沉默仍阻止技能和该次主动动作，但一次性卡牌仍消耗离场。
- 所有实体卡面统一隐藏自毁卡的 HP/ATK 徽标，手牌与等待区保留冷却数值；死亡代理也使用同一判据。
- 图鉴和详情中的原始定义数值仍保留。
