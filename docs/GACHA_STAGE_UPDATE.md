# 抽卡舞台与完成页调整

- 主界面预览卡常态显示与战斗卡同源的稀有度边缘光；悬停保留同一边缘光，仅增强至 1.3 倍，移除额外叠加光框。
- 抽卡舞台边缘光为 2.2 倍，高稀有揭晓时先偏白、再单调回落到稀有度颜色，参考 2D 项目的揭晓边框演出。完成页悬停适度增强、倾斜及前移，卡面内容不额外漂白。
- 动画结束后直接保留舞台上的实体卡，点击打开与图鉴相同的卡牌预览。不再自动弹出图片结果列表或确认弹窗。
- 完成页「离开」返回卡池选择；「继续抽卡」按本次单抽或十连直接再次提交原有经济事务，按钮显示费用。余额不足或保存失败时保留已付费的结果。跳过模式仍显示全部实体卡；重复卡依次保留。
- 背景板加入卡池图片预热，并在纹理到位时重建带 map 的材质，修复异步加载后仍沿用无贴图着色器的问题。按原图比例放置，外侧为战斗棋盘同源的木纹、倒角实体边框。
- 大背景采用缓慢流动的金白色虚空，减少动态设置可冻结；取消旧暗色场景雾，保留卡池插画与木框的可见性。
- 完成页相机留出操作按钮空间。安全网从 8 秒增至 20 秒，覆盖两倍基准耗时和纹理预热；兜底时同时收敛到最终实体卡姿态。跳过不再补发过期的揭晓爆点。
