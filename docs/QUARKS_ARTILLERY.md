# 炮击、死亡爆裂、远射与贯穿（2026-10-07）

来源：https://github.com/Alchemist0823/three.quarks （MIT）。
素材库源码提交：`de7c207f791c8b2260c43334a282976221688b1b`。运行依赖固定 `three.quarks@0.17.1`。
使用原项目 `MuzzleFlashDemo` 的 10×10 图集、烟雾与颜色/尺寸/帧动画行为，
并使用原生 Trail 渲染器。纹理及原始许可证位于 `public/assets/vfx/quarks/`。

最新 trait 语义与卡牌调整见 `TRAIT_EXPANSION.md`；贯穿已改为独立的「贯穿n」动作。

## 已实现机制

- 炮击、群体爆破：最大体积的火光、烟团、火星；仍按原有技能参数扣卡牌生命。
- 自毁：上场执行功能后离场，离场位置生成多个中体积爆炸；不再重复播放普通减益圆环。
- 爆裂、爆裂n、死亡爆裂、死亡爆裂n：离场时同时原地爆裂并向对方发炮。优先对位存活卡，无对位时选存活敌卡，无敌卡时命中本体。无数字默认 2，数字形式使用 n。
- 被死亡炮击击毁的爆裂卡在同次规则结算内连锁处理；每个共享状态组只处理一次死亡。
- 远射：替换当次普通攻击，穿过对位卡命中对方本体，伤害使用 ATK。小爆炸一次，直线烟雾在世界中持续约 6 秒（正常速度）。
- 贯穿：同样直接命中本体，金色光线持续消散，不生成爆炸；`伤害n` 覆盖该次伤害，因此「贯穿一击」实际命中 5。
- 远射/贯穿不伤害对位卡，不触发该卡的防御、闪避、反击；仍保留攻击者的攻击前其它技能和攻击后技能。
- 普通近战仍使用卡牌前冲；远程攻击不触发前冲或重复普通攻击特效。
- 沉默仍使远射/贯穿与伤害覆盖失效；不补造本轮未指定的其它 trait 机制。
- 技能元数据在 `withModernTraits` 中覆盖旧版未实现记录，保持原始导入 JSON 为旧版本的来源快照。实验台补齐所有新模板与对应卡牌。

## 时间与回收

一个共享 BatchedRenderer；演员数量沿用现有上限。每个演员独立持有其粒子系统，
结束、跳过、离开场景时立即回收；纹理、材质和批次资源在场景卸载时释放。
所有更新由现有 EffectSystem 驱动，暂停/速度档跟随原有演出控制。
拖尾坐标保持在世界中，离场代理与目标移动不改变已生成的烟雾/光线。
伤害事件和特效使用同一命中时长；原有快速逐整数扣血逻辑保留。

本轮按用户要求没有启动实例、截图、测试、类型检查或构建。
