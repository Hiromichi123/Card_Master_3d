# 战斗音效（2026-10-13）

## 本轮覆盖

本地 CC0 样本：翻牌、攻击起手、命中、斩击、火球/炮击、冰封、雷击、治疗、护盾、传送。群体技能复用同族音色，只在可见施法事件播放，不为每个目标重复施法声；伤害数字落地仍播放受限的命中声。死亡、抽卡与融合继续使用原合成音。

首次用户手势解锁后异步预载，加载未完成/失败时立即合成兜底，不延迟补播。主音量、压缩器、按 cue 限流与总预算（80 ms 最多四声）统一生效；跳过不补播攻击与施法声。音频不会参与规则结算。

## 发牌、出牌与上场

- 开局发牌沿用发牌动画起点的 `deal`；回合抽牌和技能抽牌在 `CardDrawn` 播放同一发牌声。
- `CardPlayed` 进入等待区时播放 `play`，使用独立保留的 `play.wav` 翻页样本以 0.8 倍速播放，区别于抽牌。
- `CardDeployed` 上场时播放 `deploy`，复用本地命中样本以 0.75 倍速播放，形成低沉落位声。
- 双方共用事件触发，不依赖按钮点击；不新增下载或存档字段。加载前均有独立合成兜底，跳过不补播这三类动作声音。
- 已补双方事件映射与新 cue 限流断言，未运行测试或人工试听。

## 按钮点击与纸牌发牌（2026-10-13）

- `uiClick.ts` 在 document 捕获按钮 click，覆盖登录、各场景、导航和 portal 弹窗，包括按钮内部图标；禁用、aria-disabled 和 inert 区域不响。原生按钮键盘依赖 click，自定义 role 按钮补 Enter/Space 反馈并去重，不为背景点击、文字输入或拖动播放。
- `uiClick` 使用 Kenney Interface Sounds 的 `Audio/click_001.ogg`，调用增益0.65，独立限流，不增强合并声。音量、静音、缓存、合成兜底和声部清理共用 AudioEngine。手势解锁失败静默，超过250ms或监听卸载后的迟到解锁不补播。
- `deal` 换为 Kenney Casino Audio 的 `Audio/card-slide-1.ogg`，不再用翻书代替纸牌；开局/回合/技能抽牌仍沿用原事件与动画时机。`play.wav` 保留原 `bookFlip1.ogg`，以0.8倍速播放，出牌不随发牌替换而改变。
- 已直接检查两个官方包内 License.txt，均为CC0。来源：https://kenney.nl/assets/casino-audio 、 https://kenney.nl/assets/interface-sounds 。运行时不访问外站。
- 脚本支持 `python scripts/prepare-audio.py --cues deal play uiClick`，合并清单且不重生成其他战斗音效/BGM。极短点击在淡入后再次归一化，避免瞬态被淡入削弱。所有短样本现为12个，共 **308188字节**。
