# 协力作战与高难挑战

入口：主界面 → 活动模式 → 协力作战 / 高难挑战。使用当前普通出战卡组，允许1—12张有效、库存足够的卡牌；战斗沿用现行等待区、部署与技能规则。

## 协力作战：本地共享世界 Boss

这里的“协力”是多个账号异步累计伤害，并非合作操控同一局。当前为**同一浏览器、同一站点的本地多账号共享版本**，不跨浏览器、端口或设备，不创建虚拟玩家排名。每周一北京时间04:00开启新一期。

世界Boss的**总剩余生命直接作为敌方本体生命**。每场我方本体20生命，最多30个完整回合，不限次数。结束对局（包括失败、平局、认输）后，将实际对Boss本体的扣血计为贡献；卡牌受伤、Boss自损和超额伤害不计。未完成就离开不会结算，可以回到大厅从同一开局继续。

Boss按累计伤害进入下一阶段。当前对局使用开局时的敌阵，下一场使用最新阶段的12张敌阵牌。阶段强度通过真实稀有度提升，不暗中放大ATK/HP。

同一浏览器多个标签页同时挑战时，结算在共享存储事务中串行完成，按**结算时**剩余血量截断贡献。跨过阶段边界的伤害依次分配到各阶段；阶段扣完后冻结该阶段排名。期次已结束的旧局不再计入伤害；没有打完的阶段在期次结束后也可以领取已有贡献对应的排名奖。

阶段榜只包含实际贡献账号，伤害降序；同伤害按固定账号ID排序。每阶段每账号领取一次：

大厅可切换历史期次、阶段补领排名奖，历史里程碑也可补领。新一期独立累计。

## 高难挑战：三日公开敌阵

以2026-10-15北京时间04:00为起点，每72小时轮换一次。所有账号在同一期看到相同的12张公开卡组。卡牌以A/A+/S为主，含SS牌；轮换空域压制、要塞攻坚、元素洪流、亡者反扑等主题倾向。敌方本体40生命，我方20生命，最多30个完整回合，AI使用困难规则推演。

不限制次数，可以根据公开敌阵重新配置卡组。每期首次胜利1000金币、100水晶；每个额外目标增加20%基础奖励，即200金币、20水晶：

- 本体全程没有任何扣血：按照实际扣血事件累计，受伤后治疗回满也不满足。
- 少于15个完整回合获胜：最终轮次严格小于15。
- 获胜时普通手牌超过6张：严格大于6，冷却牌不计。

每期最高1600金币、160水晶。三个目标可分别在不同胜场达成；已经发放的目标不因重复获胜而再次发奖。败局不发资源，但所有完成的对局都计入非深渊战斗统计。跨期才结束的已开战挑战仍按它原来的期次结算。

## 保存、恢复和维护

- 共享数据库：`card-master-activity-local-v1`，`cycles`对象仓库保存期次、贡献、阶段冻结榜、开战凭据与结算凭据。
- 开战先持久化完整配置和种子，刷新后可以从同一局的**开局**继续；不保存逐回合进度。可以主动放弃未完成挑战再开启新局。
- 规则终局同步收集`PlayerHpChanged`事件并产生战果，独立于动画速度、跳过演出或结果面板播放。
- 先在共享事务中确认一次伤害和不可变结算凭据，再通过`ProfileStore.commitEconomic`将资源、个人收据账本、目标达成位和战斗统计原子写入当前账号。
- 若个人存档写入失败，大厅提供“恢复入账”。重复提交同一凭据不会重复扣Boss生命或发奖。
- 个人存档格式升为v10，v9自动补空活动账本；其它账号资产和进度保持。玩家存档导出包含个人领奖记录，**不包含全局共享世界Boss数据库**。
- 参数集中于`src/domain/progression/activityModes.ts`。真实共享读写与原子结算在`src/services/activity/activityRepository.ts`；界面和战斗衔接在`src/scenes/ActivityModeScene.tsx`。
- 后续接服务器时，用服务端替换共享仓库接口，并在服务端验证战斗记录、身份和奖励；当前浏览器本地版本不具备跨设备权威排行能力。

阶段实现时未运行验证；v3.3发布打包执行了 `npm run build`（类型检查与生产构建），未启动实例、截图或运行测试套件。新增的测试源码覆盖期次边界、跨阶段分摊、并发末刀截断、收据重试、额外目标补领奖励和存档迁移，留待需要验证时运行。
