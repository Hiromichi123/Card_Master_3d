# Card Master 3D 游戏规则总文档

规则版本：2026-10-12 · 手动部署、客场先部署与残局自动演进。适用：演示战斗、战役以及本地选卡对战使用的统一战斗引擎。

本文件是当前规则入口，包含回合流程、冷却牌、插队、结算和已有 traits。旧版源码考据另存于
[rules.md](rules.md)，不再作为现行玩法说明。图鉴中未实现的词条不自动获得推测机制。

## 1. 对局与区域

| 项目 | 默认规则 |
| --- | --- |
| 本体生命 | 双方各 20 |
| 牌组 | 每方最多 12 张普通卡；允许重复 |
| 开局手牌 | 双方各从牌组抽 3 张，牌堆不足则抽尽 |
| 开局先后手 | 通过本局随机种子等概率决定；后手额外得到一张冷却牌 |
| 新主场抽牌 | 交棒给新的主场时，从该方牌堆抽 1 张；牌堆空则不抽 |
| 等待区 | 每方固定 8 槽，冷却完成也继续占槽 |
| 战斗区 | 每方固定 5 槽，组成从左到右连续排列的队列 |
| 普通出牌额度 | 每个主场回合最多 1 张；可选择不出 |
| 上场额度 | 不限张数，逐张部署，但当次部署必须有战斗空位 |
| 对局上限 | 正常操作最多 200 轮；残局自动演进期间优先采用 10 次主场行动的本体血量判定 |

“主场”是该次回合的持有方，“客场”是对方。当前操作方可以临时是客场，但主场身份和
回合编号不会因此改变。开局先后手仍随机决定；每回合的部署顺序固定为客场先、主场后。

冷却牌属于本局临时资源，不进入藏品、组卡、抽卡池或持久化奖励，也不计入普通牌组上限。
重复开局使用新的局内种子；保存相同种子与命令序列仍可复现相同规则结果。

## 2. 出牌、跳过和冷却牌

1. 主场可将最多一张普通手牌放入任意空等待槽，放入时使用卡牌基础 CD。
2. 等待区满时不能打入普通牌；先部署成熟卡腾出槽位后可以继续出牌。
3. 可以不打普通牌而结束行动。该次主场结束时自动获得一张冷却牌，仅获得一次。
   “跳过”只跳过普通出牌，已经部署的卡仍结算技能和攻击；使用冷却牌或部署不影响领取资格。
4. 本回合已经打过普通牌，则结束时不领取跳过奖励。客场部署完成不能领取奖励。
5. 冷却牌指定己方等待区一张 CD > 0 的卡，使其 CD−1，最低为 0，用后立即消耗。
   它不进入等待区，不占普通出牌额度，也没有每回合使用数量限制。
6. 冷却牌只能在己方主场操作阶段使用，不能作用于手牌、战斗区、敌方卡或 CD 已为 0 的卡。
   没有合法目标时保留在手牌，不能空放消耗。
7. 消耗的冷却牌直接移除，不加入弃牌堆，无法通过还魂、不死、复活或吞噬回收/利用。
   如果一方只剩冷却牌且所有普通牌相关区域已空，仍判定其无可战斗卡牌。

操作：点击普通手牌，再点击空等待槽；点击冷却牌，再点击己方等待区中仍在冷却的卡。

## 3. 双边冷却与成熟状态

每完成一个主场回合并交棒，双方等待区中 CD > 0 的卡各减 1。冷却推进一次，
不会因为客场部署、使用冷却牌或逐张上场而额外推进。

CD 归零只表示“可以上场”，卡牌保持在等待区，卡边变为金色，不自动进入战斗区。
玩家可以保留成熟卡；成熟卡仍占等待槽、仍能受延迟技能影响。
如果成熟卡受到延迟后 CD 再次大于 0，金边消失，必须重新冷却完成。
基础 CD 为 0 的卡打进等待区后即可在同一主场部署。

由于双方交棒均减 CD，从当前操作阶段放入等待区的卡，奇数 CD 通常在对方主场成熟，
偶数 CD 通常在自己的主场成熟。加速、延迟和冷却牌会改变这个节奏。

## 4. 固定客场先部署

交棒完成双方CD递减和新主场抽牌后，客场等待区只要有成熟卡，就先开放客场部署窗口。
不再让主场选择先手或后手；主场必须等待客场完成部署或选择不上场，然后才能操作并攻击。
客场没有成熟卡时直接进入主场操作。满场的客场仍可选择跳过，成熟卡继续保留在等待区。

顺序固定：客场仅部署或跳过 → 主场出牌、使用冷却牌、部署 → 主场技能与整排攻击 → 交棒。

客场窗口不额外抽牌，不打普通牌，不使用冷却牌，不进行整排攻击，不触发自身回合技能，
不获得跳过奖励，不刷新CD或临时状态期限。客场可连续部署多张，也可以一张都不上场。
客场部署立即触发上场技能，自毁卡正常施放并离场；可能当场结束对局。
一个主场只开放一次前置客场窗口，攻击结束后不再追加窗口；已结束的对局不继续部署。

战斗设置新增“跳过回合结束”，默认关闭并随账号设置保存。开启时，当前人类操作方若
没有合法普通出牌、可使用的冷却牌或可部署成熟卡，下方回合操作按钮隐藏；等待1秒后
自动提交完成部署/结束行动，走相同技能与攻击结算管线。成熟卡可部署、冷却牌有目标时
仍需玩家决策。满战斗区无法部署不算可用操作；没有目标的冷却牌也不阻止自动推进。
客场自动完成只交还操作权，不能攻击或领取冷却牌。1秒等待不受正常/快速/跳过演出影响，
关闭开关、重开或离开战斗取消等待；演出和AI操作期间不累计人类等待时间。

## 5. 手动上场、插队与拖放

只允许从己方等待区部署 CD = 0 的卡；普通手牌不能越过等待区直接上场。

已有 k 张战斗卡且 k < 5 时，可插入的位置为第 1 到第 k+1 槽：
第 1 槽为头插，第 k+1 槽为尾插，中间位置为插队。已有三张时只可放在第 1～4 槽，
不能直接放在第 5 槽留下空位。空战斗区只可放第 1 槽，满五张时不可部署。

插入时，原插入点及其后的卡向后移动一槽；所有原有卡牌保持相对顺序。
不允许挤出末尾、自动牺牲原卡或直接拖动已在场卡进行自由重排。
位置变化立即改变对位、沉默与位置相关技能关系；它不再次触发原卡的上场技能或飞行入场圆阵。

操作：

- 拿起成熟卡时放大到战斗区卡牌尺寸，跟随鼠标移动。
- 移入合法插入位置时，预览后方卡牌让位；左右移动可继续调整插入点。
- 预览期间规则状态不变，松手到合法位置才提交本次部署。
- 放回等待区、放到非法位置、按 Esc、指针取消或窗口失焦，均取消并恢复原位置。
- 也可点击成熟卡选中，再点击高亮战斗槽完成部署。
- 多张卡分别部署，每张落位后重新计算可插入位置及上场技能产生的实际空位。

上场技能、自毁、分身或召唤可能改变剩余空位，因此不能预先承诺整批卡一定都能放下。
死亡离场后的队列会按既有相对顺序压紧；已在攻击结算中的死亡仍遵循原攻击管线，
整排结束再整理，避免因即时重排导致同一张卡在一次整排行动中重复攻击。

## 6. 攻击、状态、死亡与胜负

普通部署完成后不会立刻发起整排攻击。主场手动或无操作自动结束行动时：

1. 在场可行动卡依次触发自身回合技能，如献祭、传送。
2. 调度主场整排攻击：先攻单位优先，多个先攻仍按槽位顺序，其余按槽位顺序。
3. 每张行动卡先处理攻击前技能，再按现有机制进行普通攻击；本次新上场的普通卡可正常行动。
4. 伤害、反击、临时状态发作和死亡技能按原管线处理；单张卡在同一次整排行动中至多被调度一次。
5. 清理到期状态、不屈期限、死亡与队列空位。
6. 结束该次主场并交棒；新回合的客场成熟卡固定先部署。

对位指双方同下标战斗槽。本体是双方基础生命。空对位的普通攻击打本体；飞行、对空、
攻城、远射、先锋等会进一步影响普通攻击目标。普通攻击仍表现为卡牌前冲返回，受击数值连续快速回落。

每个主场行动具有单调增加的编号；客场部署不增加编号。
一回合状态与不屈按照所属方下一次完整主场行动计算，不因随机开局或客场操作提前过期。

本体 HP 降至 0，或牌堆、普通手牌、等待区、战斗区均无可战斗卡牌，则进入失败处理。
弃牌堆和冷却牌不能单独维持继续对局的资格。一个已完成的技能/攻击或部署结算节点后检查胜负；
双方在该节点同时满足失败条件则平局，结束后不再开放后续操作。达到回合上限也判平局。

## 7. 当前人机 AI

AI 与人类提交同一种命令，使用同一合法性判定，不修改权威状态绕过规则。

- 默认规则策略：枚举合法出牌、冷却牌目标、成熟卡插队与结束窗口，评分并进行有限的引擎推演；可以选择保留成熟卡或跳过普通出牌。
- 简单、普通、困难、Boss 通过不同搜索预算与少量探索区分，不额外增加卡牌数值。深渊普通/困难/噩梦分别采用普通/困难/Boss。
- 均衡、进攻、防守、控制调整评分侧重，不改变回合与 trait 规则。
- 观察只使用公开区域、自身手牌与自身剩余牌组组成；不读取真实敌方未知手牌、牌堆顺序或未来 RNG。未知局面通过公共卡库采样。同机本地模式可采用公开手牌观察。
- 保留旧版基础策略：短 CD 出牌、尽量使用冷却牌和部署成熟卡、随机插入。
- 支持导入离线学习的评分权重或小模型与规则推演融合。没有导入时使用规则策略；模型也必须经过相同的合法动作约束。

权重优化、小模型训练、评测工具和施工状态见 [AI_SYSTEM.md](AI_SYSTEM.md) 与 [AI_CHECKLIST.md](AI_CHECKLIST.md)。本次未训练或运行验证，难度强弱和性能尚未标定。

## 8. 规则与演出边界

命令由纯规则引擎一次性产生事件、数值补丁与最终状态。3D 渲染、拖放预览、音效、
正常/快速/跳过演出都只展示这些结果，不自行决定伤害、目标或冷却。
客场控制权独立于主场身份；AI、下方玩家和本地上方玩家都通过当前操作方接收输入。

## 9. 已有 Trait 功能总表

更新：2026-10-08。按当前 3D 版本整理，同类功能合并。`n` 表示卡面上的数值；“对位”指双方战斗区同下标槽位，“本体”指玩家生命。

除特别说明外，主动攻击技能在该卡攻击前结算，随后仍进行普通攻击。技能伤害不会因为目标飞行而转移到本体；剑舞、献祭、坍缩返伤与直接击杀使用独立扣血/离场路径。不屈可暂缓这些扣血造成的首次死亡，到期后再正常离场。献祭和传送在自身回合的部署结束后、整排攻击前，每张在场卡触发一次。

| --- | --- |
| 火球n / 冰封n / 闪电n / 炮击n | 对随机敌方战斗单位造成 n 点技能伤害，分别使用火、冰、雷和炮击特效。冰封目前不额外冻结或跳过回合。 |
| 群体火球n / 群体冰封n / 群体闪电n / 群体爆破n | 对敌方全部战斗单位各造成 n 点技能伤害。 |
| 斩击n | 对当前对位造成 n 点技能伤害，使用两道交叉弧斩；对位为空时跳过。 |
| 群体斩击n | 对敌方全部战斗单位各造成 n 点技能伤害，各播放双弧斩击；兼容“群体斩n击”写法。 |
| 剑舞n / 群体剑舞n | 对当前对位 / 敌方全体各直接扣除 n HP，无视飞行、防御、闪避、免疫、圣盾和法术反弹。多段多方向圆弧刀光只表现一次 n 点扣血。 |

| 重伤n | 赋予时机和一回合期限同上；贴卡面且清晰的深红受伤法阵、深暗红遮罩，无流血粒子；发作使用与严霜同样的卡面掩膜开裂、碎片飞散，改为深红色。受赋予卡下一次主动普攻后 ATK 减少 n，下限为 0，到期或离场时加回实际减少量，保留其它增益与减益。 |
| 毒雾n | 攻击前选随机敌方，绿色无实体毒气团沿火球抛物线落到卡面爆发，造成随机 1–n 点技能伤害，并给仍存活的目标赋予剧毒n；可被法术反弹。 |
| 伤害n / 群体伤害n | 对随机敌方 / 敌方全体分别进行一次 n 点普通攻击，遵循飞行、防御、圣盾、闪避和反击规则。 |
| 贯穿n | 独立对敌方本体造成 n 点伤害，金色直线光尾，无爆炸；不改变普通攻击的目标。 |

| 临点坍缩 | 普攻真正命中对位卡时，若减伤、闪避结算后的伤害超过对位命中前剩余 HP，将超出的部分直接返还给自己，自己卡面播放红色双弧斩击。打空槽、远射或飞行改道不触发。 |
| 不屈 | 首次 HP 归零后暂不离场，继续普攻、施法、占位与接受目标选择，到下一个自身回合结束后再进入死亡离场流程。持续期间卡面覆盖鲜红外溢边缘、较暗中心的遮罩；重复致命伤害不刷新期限，恢复 HP 也不取消到期离场。 |
| 远射 | 使普通攻击越过对位卡牌直接命中敌方本体，小爆炸并留下长直线烟雾拖尾。 |
| 即死n | 随机敌方战斗单位 HP 立即清零并触发死亡处理，使用黑色诅咒。n 为保留的等级参数，不改变必杀结果。 |
| 斩杀 | 己方回合攻击前，如果对位当前 HP 严格低于自身当前 HP，直接击杀对位并使其离场，使用深红剑舞。对位为空、同血或更高血量时跳过；兼容旧卡面“斩杀3”，数字不作为固定血量阈值。 |

| 群体爆裂n | 死亡离场时原地爆裂，并对敌方全部战斗单位各触发炮击；未带数字时默认 2 点伤害，敌方战斗区为空时跳过炮击，不改为命中本体。 |

## 10. 融合工坊

投入五张可融合的普通卡牌，消耗材料并获得一张随机卡。概率预览与实际抽取使用同一分布；没有合法产出或保存失败时不消耗材料。

融合按配置的稀有度顺序计算，包括 `+` 档位。每张材料只向自身及上下各两档贡献权重：本档 1.0，向上第一 / 第二档 0.35 / 0.175，向下第一 / 第二档 0.2 / 0.1。超出顺序边界的档位忽略；无可用卡的档位剔除，再将五张材料的贡献相加、归一化。
取消所有稀有度通用的基础权重，因此远离材料范围的稀有度概率为零。例如全部投入 D，产出只能是 D、C 或 C+（对应档位须有可用卡），不会直接获得 B、A、S 或 SSS；混合材料的范围是各材料允许档位的并集。

牌库位于工坊左侧，每行六张。祭坛采用正前方俯视，融合时合成台与材料、法阵同步加速旋转，再随结果揭示减速停下；完整转数使停止后的祭坛重新正面朝向玩家。跳过演出直接进入静止结果，卡牌仍可详细检视。
