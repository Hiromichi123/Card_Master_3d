# Card Master 3D 游戏规则总文档

规则版本：2026-10-09 · 手动部署与抢先。适用：演示战斗、战役以及本地选卡对战使用的统一战斗引擎。

本文件是当前规则入口，包含回合流程、冷却牌、插队、结算和已有 traits。旧版源码考据另存于
[rules.md](rules.md)，不再作为现行玩法说明。图鉴中未实现的词条不自动获得推测机制。

## 1. 对局与区域

| 项目 | 默认规则 |
| --- | --- |
| 本体生命 | 双方各 20 |
| 牌组 | 每方最多 12 张普通卡；允许重复 |
| 开局手牌 | 双方各从牌组抽 3 张，牌堆不足则抽尽 |
| 开局先后手 | 通过本局随机种子等概率决定；后手额外得到一张冷却牌 |
| 新主场抽牌 | 交棒给新的主场时，从该方牌堆抽 1 张；牌堆空则不抽 |
| 等待区 | 每方固定 8 槽，冷却完成也继续占槽 |
| 战斗区 | 每方固定 5 槽，组成从左到右连续排列的队列 |
| 普通出牌额度 | 每个主场回合最多 1 张；可选择不出 |
| 上场额度 | 不限张数，逐张部署，但当次部署必须有战斗空位 |
| 对局上限 | 200 轮，双方各完成一次主场为一轮；到上限未分胜负则平局 |

“主场”是该次回合的持有方，“客场”是对方。当前操作方可以临时是客场，但主场身份和
回合编号不会因此改变。开局先后手与每个回合的“抢先选择”是两件不同的事。

冷却牌属于本局临时资源，不进入藏品、组卡、抽卡池或持久化奖励，也不计入普通牌组上限。
重复开局使用新的局内种子；保存相同种子与命令序列仍可复现相同规则结果。

## 2. 出牌、跳过和冷却牌

1. 主场可将最多一张普通手牌放入任意空等待槽，放入时使用卡牌基础 CD。
2. 等待区满时不能打入普通牌；先部署成熟卡腾出槽位后可以继续出牌。
3. 可以不打普通牌而结束行动。该次主场结束时自动获得一张冷却牌，仅获得一次。
   “跳过”只跳过普通出牌，已经部署的卡仍结算技能和攻击；使用冷却牌或部署不影响领取资格。
4. 本回合已经打过普通牌，则结束时不领取跳过奖励。客场部署完成不能领取奖励。
5. 冷却牌指定己方等待区一张 CD > 0 的卡，使其 CD−1，最低为 0，用后立即消耗。
   它不进入等待区，不占普通出牌额度，也没有每回合使用数量限制。
6. 冷却牌只能在己方主场操作阶段使用，不能作用于手牌、战斗区、敌方卡或 CD 已为 0 的卡。
   没有合法目标时保留在手牌，不能空放消耗。
7. 消耗的冷却牌直接移除，不加入弃牌堆，无法通过还魂、不死、复活或吞噬回收/利用。
   如果一方只剩冷却牌且所有普通牌相关区域已空，仍判定其无可战斗卡牌。

操作：点击普通手牌，再点击空等待槽；点击冷却牌，再点击己方等待区中仍在冷却的卡。

## 3. 双边冷却与成熟状态

每完成一个主场回合并交棒，双方等待区中 CD > 0 的卡各减 1。冷却推进一次，
不会因为选择先后手、客场部署、使用冷却牌或逐张上场而额外推进。

CD 归零只表示“可以上场”，卡牌保持在等待区，卡边变为金色，不自动进入战斗区。
玩家可以保留成熟卡；成熟卡仍占等待槽、仍能受延迟技能影响。
如果成熟卡受到延迟后 CD 再次大于 0，金边消失，必须重新冷却完成。
基础 CD 为 0 的卡打进等待区后即可在同一主场部署。

由于双方交棒均减 CD，从当前操作阶段放入等待区的卡，奇数 CD 通常在对方主场成熟，
偶数 CD 通常在自己的主场成熟。加速、延迟和冷却牌会改变这个节奏。

## 4. 抢先与客场部署窗口

交棒完成双边 CD 递减、给新主场抽牌后，如果客场等待区有成熟卡，先暂停普通操作，
由主场选择本次行动顺序。包括此前保留的成熟卡；即使客场当前满场也可以选择顺序，
因为主场先攻击可能为客场腾出空位。

| 主场选择 | 操作与结算顺序 |
| --- | --- |
| 先手 | 主场出牌/用冷却牌/部署 → 主场技能与整排攻击 → 客场仅部署成熟卡或不上场 → 交棒 |
| 后手 | 客场仅部署成熟卡或不上场 → 主场出牌/用冷却牌/部署 → 主场技能与整排攻击 → 交棒 |
| 客场没有成熟卡 | 主场直接操作并攻击 → 交棒，无需选择抢先 |

客场窗口不额外抽牌，不打普通牌，不使用冷却牌，不进行整排攻击，不触发自身回合技能，
不获得跳过奖励，不刷新 CD 或临时状态期限。客场可连续部署多张，也可以一张都不上场。

客场部署的卡立即触发自身上场技能。自毁卡立即施放并离场，可能当场造成伤害或结束对局；
这是该卡的上场功能，不代表客场获得完整攻击回合。普通客场单位到自己的主场再进行常规行动。

同一个主场最多只有一个客场部署窗口，不来回抢先或反复响应。主场选先手后若攻击结束时
客场已没有成熟卡，则直接交棒。对局已结束时也不继续打开部署窗口。

## 5. 手动上场、插队与拖放

只允许从己方等待区部署 CD = 0 的卡；普通手牌不能越过等待区直接上场。

已有 k 张战斗卡且 k < 5 时，可插入的位置为第 1 到第 k+1 槽：
第 1 槽为头插，第 k+1 槽为尾插，中间位置为插队。已有三张时只可放在第 1～4 槽，
不能直接放在第 5 槽留下空位。空战斗区只可放第 1 槽，满五张时不可部署。

插入时，原插入点及其后的卡向后移动一槽；所有原有卡牌保持相对顺序。
不允许挤出末尾、自动牺牲原卡或直接拖动已在场卡进行自由重排。
位置变化立即改变对位、沉默与位置相关技能关系；它不再次触发原卡的上场技能或飞行入场圆阵。

操作：

- 拿起成熟卡时放大到战斗区卡牌尺寸，跟随鼠标移动。
- 移入合法插入位置时，预览后方卡牌让位；左右移动可继续调整插入点。
- 预览期间规则状态不变，松手到合法位置才提交本次部署。
- 放回等待区、放到非法位置、按 Esc、指针取消或窗口失焦，均取消并恢复原位置。
- 也可点击成熟卡选中，再点击高亮战斗槽完成部署。
- 多张卡分别部署，每张落位后重新计算可插入位置及上场技能产生的实际空位。

上场技能、自毁、分身或召唤可能改变剩余空位，因此不能预先承诺整批卡一定都能放下。
死亡离场后的队列会按既有相对顺序压紧；已在攻击结算中的死亡仍遵循原攻击管线，
整排结束再整理，避免因即时重排导致同一张卡在一次整排行动中重复攻击。

## 6. 攻击、状态、死亡与胜负

普通部署完成后不会自动发起整排攻击。主场确认结束行动时：

1. 在场可行动卡依次触发自身回合技能，如献祭、传送。
2. 调度主场整排攻击：先攻单位优先，多个先攻仍按槽位顺序，其余按槽位顺序。
3. 每张行动卡先处理攻击前技能，再按现有机制进行普通攻击；本次新上场的普通卡可正常行动。
4. 伤害、反击、临时状态发作和死亡技能按原管线处理；单张卡在同一次整排行动中至多被调度一次。
5. 清理到期状态、不屈期限、死亡与队列空位。
6. 若主场选先手，进入尚有成熟卡的客场部署窗口；否则结束该次主场并交棒。

对位指双方同下标战斗槽。本体是双方基础生命。空对位的普通攻击打本体；飞行、对空、
攻城、远射、先锋等会进一步影响普通攻击目标。普通攻击仍表现为卡牌前冲返回，受击数值连续快速回落。

每个主场行动具有单调增加的编号；客场部署不增加编号。
一回合状态与不屈按照所属方下一次完整主场行动计算，不因随机开局、抢先或客场操作提前过期。

本体 HP 降至 0，或牌堆、普通手牌、等待区、战斗区均无可战斗卡牌，则进入失败处理。
弃牌堆和冷却牌不能单独维持继续对局的资格。一个已完成的技能/攻击或部署结算节点后检查胜负；
双方在该节点同时满足失败条件则平局，结束后不再开放后续操作。达到回合上限也判平局。

## 7. 当前基础 AI

AI 与人类提交同一种命令，使用同一合法性判定，不修改权威状态绕过规则。

- 普通牌：沿用优先最短基础 CD 的策略，同 CD 用局内 AI 随机器打破平局。
- 冷却牌：己方主场有合法目标就使用，优先当前 CD 最短的冷却中卡；没有目标则保留。
- 抢先：先手/后手等概率随机。
- 上场：按等待区顺序尝试所有成熟卡，不主动囤成熟牌；插入位置从合法位置中随机选择。
- 满场：保留暂时无法上场的卡，不挤出既有单位。
- 客场：只部署，不额外出普通牌、攻击或领取跳过奖励。
- 没有可继续执行的操作时，完成客场部署或结束主场；未打普通牌则按规则取得冷却牌。

本版尚未加入搜索、人机难度训练或学习模型。

## 8. 规则与演出边界

命令由纯规则引擎一次性产生事件、数值补丁与最终状态。3D 渲染、拖放预览、音效、
正常/快速/跳过演出都只展示这些结果，不自行决定伤害、目标或冷却。
客场控制权独立于主场身份；AI、下方玩家和本地上方玩家都通过当前操作方接收输入。

## 9. 已有 Trait 功能总表

更新：2026-10-08。按当前 3D 版本整理，同类功能合并。`n` 表示卡面上的数值；“对位”指双方战斗区同下标槽位，“本体”指玩家生命。

除特别说明外，主动攻击技能在该卡攻击前结算，随后仍进行普通攻击。技能伤害不会因为目标飞行而转移到本体；剑舞、献祭、坍缩返伤与直接击杀使用独立扣血/离场路径。不屈可暂缓这些扣血造成的首次死亡，到期后再正常离场。献祭和传送在自身回合的部署结束后、整排攻击前，每张在场卡触发一次。

| --- | --- |
| 火球n / 冰封n / 闪电n / 炮击n | 对随机敌方战斗单位造成 n 点技能伤害，分别使用火、冰、雷和炮击特效。冰封目前不额外冻结或跳过回合。 |
| 群体火球n / 群体冰封n / 群体闪电n / 群体爆破n | 对敌方全部战斗单位各造成 n 点技能伤害。 |
| 斩击n | 对当前对位造成 n 点技能伤害，使用两道交叉弧斩；对位为空时跳过。 |
| 群体斩击n | 对敌方全部战斗单位各造成 n 点技能伤害，各播放双弧斩击；兼容“群体斩n击”写法。 |
| 剑舞n / 群体剑舞n | 对当前对位 / 敌方全体各直接扣除 n HP，无视飞行、防御、闪避、免疫、圣盾和法术反弹。多段多方向圆弧刀光只表现一次 n 点扣血。 |
| 溅射 | 普攻命中对位时，对位仍受正常普攻，其相邻左右槽各受到 floor(原始 ATK / 2) 点普攻伤害；不向空相邻槽发起额外攻击，边缘只处理存在的一侧。相邻伤害分别走飞行、防御、圣盾、闪避和受击反击，不重复前冲或触发攻击者的攻击后技能。 |

| 毒雾n | 攻击前选随机敌方，绿色无实体毒气团沿火球抛物线落到卡面爆发，造成随机 1–n 点技能伤害，并给仍存活的目标赋予剧毒n；可被法术反弹。 |
| 伤害n / 群体伤害n | 对随机敌方 / 敌方全体分别进行一次 n 点普通攻击，遵循飞行、防御、圣盾、闪避和反击规则。 |
| 贯穿n | 独立对敌方本体造成 n 点伤害，金色直线光尾，无爆炸；不改变普通攻击的目标。 |

| 临点坍缩 | 普攻真正命中对位卡时，若减伤、闪避结算后的伤害超过对位命中前剩余 HP，将超出的部分直接返还给自己，自己卡面播放红色双弧斩击。打空槽、远射或飞行改道不触发。 |
| 不屈 | 首次 HP 归零后暂不离场，继续普攻、施法、占位与接受目标选择，到下一个自身回合结束后再进入死亡离场流程。持续期间卡面覆盖鲜红外溢边缘、较暗中心的遮罩；重复致命伤害不刷新期限，恢复 HP 也不取消到期离场。 |
| 远射 | 使普通攻击越过对位卡牌直接命中敌方本体，小爆炸并留下长直线烟雾拖尾。 |
| 即死n | 随机敌方战斗单位 HP 立即清零并触发死亡处理，使用黑色诅咒。n 为保留的等级参数，不改变必杀结果。 |
| 斩杀 | 己方回合攻击前，如果对位当前 HP 严格低于自身当前 HP，直接击杀对位并使其离场，使用深红剑舞。对位为空、同血或更高血量时跳过；兼容旧卡面“斩杀3”，数字不作为固定血量阈值。 |
| 自毁 | 上场立即完成自身技能与一次有效攻击，然后 HP 清零离场；一次性卡牌在场不显示 HP、ATK。 |
| 群体爆裂n | 死亡离场时原地爆裂，并对敌方全部战斗单位各触发炮击；未带数字时默认 2 点伤害，敌方战斗区为空时跳过炮击，不改为命中本体。 |
| 爆裂n / 爆裂 | 死亡离场时，向死亡槽位的敌方对位发出一次炮击，造成 n 点技能伤害；对位为空跳过，不改打本体。无数字默认 2。与群体爆裂的群体范围分别结算。 |
| 召唤狐灵 / 狐灵召唤 | 上场后在己方第一个空战斗槽召唤独立的 #yoroi_009 火 焰 狐 灵（ATK 0 / HP 3 / 火球2），直接在场不等待 CD；满场跳过，不消耗藏品或牌组。 |
| 隐匿 | 每次进入战斗区后，规避真正命中自己的第一次普通攻击，包括伤害n和溅射的普通命中。技能伤害、真伤、即死和直击本体不消耗隐匿；规避成功后本次减伤/闪避不再重复抽取。每个分身/复制实例分别记一次。 |
| 先攻 | 无视原槽位先于己方普通单位行动；多个先攻仍按原槽位从前到后。只改变攻击调度，不交换槽位或对位。 |
| 吞噬 | 攻击前清空敵方全部弃牌；牌堆、手牌和场上单位不受影响，被吞噬的牌不能再被还魂回收。空弃牌堆时跳过。 |
| 至高之作 | 上场后在己方第一个空战斗槽召唤一张满血、独立状态的 A+_006 蒸汽艺术（ATK 2 / HP 6，飞行、火球1），立即在场，不消耗牌组或藏品，也不再次等待原 CD 5。没有空位时跳过。 |
| 先锋 | 在场且 HP>0 时优先替队友承受能够命中的普通攻击，包括伤害n和溅射；多个先锋按槽位顺序选择一张，先锋自己受攻不再相互转移。实际承受者正常触发隐匿、减伤、闪避和反击；不替本体承受远射/攻城、空槽攻击或飞行改道，也不接法术或真伤。无法被当前地面攻击命中的飞行先锋不拦截。 |
| 必杀n | 攻击前以 20%−10%×0.5^(n−1) 的概率直接击杀当前对位：1级10%、2级15%、3级17.5%，上限20%。成功时播放黑色即死动画，失败时不播放；不属于来袭法术，不被法术反弹或先锋拦截，仍保留不屈等正常离场机制。 |
| 对空 | 自身普攻（包括伤害n产生的普通命中）能够攻击飞行单位，正常触发防御、圣盾、闪避与反击；不会因此变成飞行单位。无额外动画。 |
| 群体禁飞 | 持有者在场且未被对位沉默时，持续压制敌方全部在场飞行单位，使其落地并可被地面普攻。包含后续上场的飞行卡；所有光环持有者离场或被沉默后，原飞行卡恢复飞行。属性光环不作为法术反弹，无额外施法动画。 |
| 攻城 | 自身普攻越过对位卡直接打敌方本体，保留普通卡牌前冲，不发射弹体、爆炸或烟雾；不触发被越过卡的受击反击和溅射。与远射同在时优先使用攻城表现，无额外技能动画。 |
| 飞行 | 未被群体禁飞压制时，不受不具对空的地面单位普攻；地面普攻穿过自己，攻击己方本体。飞行单位的普攻可以命中飞行单位，技能伤害仍可命中。 |
| 防御n | 每次受普通攻击时减免 n 点伤害，减免量会被破甲抵消；不减免技能伤害。 |
| 圣盾n | 每次受到普通攻击或普通技能伤害时减免 n 点，不受破甲影响；不挡真伤、献祭或直接击杀。 |
| 破甲n | 对位有防御时，为本次普通攻击提供 n 点破甲，抵消相应防御减伤。 |
| 闪避n | 按等级概率闪避普通攻击：1 / 2 / 3 级分别为 30% / 60% / 75%，继续升级渐近 90%。 |
| 闪避赋予n | 把闪避n赋予随机友方，优先其它友方，持续至该卡离场；重复赋予与原有闪避取最高等级，使用金色破甲动画。 |
| 法术反弹 | 持有者在场时保护己方，将敌方来袭法术整次返回施法方，包括群体法术和传送；一次法术只反射一次。普通攻击、远射、贯穿、剑舞与斩杀不反弹。 |
| 献祭n | 每个自身回合，从其它在场友方总共抽取至多 n 点生命恢复自身。随机选取来源，不足时继续取其它友方；按实际抽取量回血，达到生命上限立即停止。没有可用友方或自身满血时跳过，使用吸血动画。 |
| 传送 | 每个自身回合随机打乱敌方战斗区卡牌顺序，更新对位关系；保持已有空槽位置，少于两张存活敌方时跳过。兼容旧卡面“传送1”。 |
| 治愈n / 治疗n | 治疗随机一张受伤友方 n HP，优先其它受伤友方，最多恢复到生命上限；没有受伤友方时跳过。 |
| 群体治愈n | 治疗全部受伤友方各 n HP，最多恢复到各自生命上限。 |
| 恢复n | 恢复自身 n HP，最多到生命上限，满血时跳过。 |
| 吸血n | 一次攻击确实造成伤害后，恢复自身固定 n HP，最多到生命上限。 |
| 祝福n / 群体祝福n | 随机友方（优先其它友方）/ 全部友方的 ATK 与当前 HP 各增加 n；当前实现允许 HP 超过基础上限。 |
| 振奋n / 群体振奋n | 上场时，随机友方 / 全部友方的 ATK 增加 n，不增加 HP。 |
| 诅咒n | 使当前对位的 ATK 降低 n，最低为 0，使用紫色束缚动画。 |
| 受伤n | 攻击后自身受到 n 点自伤，可以导致死亡；使用红色低矮束缚动画。 |
| 狂暴 / 狂暴1 | 当前 ATK = 其它增减益作用后的基础 ATK + max(0, 生命上限 − 当前 HP)，最低为 0。受到伤害立即加攻，回血立即回落；不再主动自伤，也不永久累计加攻，无额外动画。共享分身只维护一份加成，独立复制保留独立数值。 |
| 反击n | 受到普通攻击且确实损失生命后，对攻击者造成 n 点技能伤害。 |
| 沉默 | 压制当前对位卡的主动技能与受击技能；位置改变后重新判定，死亡系 trait 仍按原有离场规则执行。 |
| 抽卡n | 从己方牌堆抽 n 张到手牌；剩余牌堆不足 n 张时不触发。 |
| 还魂n | 从己方弃牌堆取回 n 张到手牌，重置不死/复活标记；不足 n 张时不触发。 |
| 加速n | 己方最左侧已占用准备槽的 CD 减少 n，最低为 0。 |
| 延迟n / 延时n | 敌方最左侧已占用准备槽的 CD 增加 n。 |
| 分身 | 上场时在空友方战斗槽生成分身，共享 HP、ATK 等状态；同组生命耗尽时整组离场。 |
| 复制 | 攻击前在空友方战斗槽生成独立复制体；己方每回合最多一次。 |
| 不死 | 死亡后恢复生命并返回手牌，可以再次上场，没有单次消耗限制。 |
| 复活 | 死亡后恢复生命并返回空准备槽，重新冷却；每次生命周期只能触发一次，没有空准备槽时失败。 |

五种攻击后状态各自独立，持续到受赋予卡下一个自身回合结束；同类重复赋予取较高 n 并刷新一回合期限，异类可以共存；刷新重伤卡面状态不延长已经发生的临时 ATK 扣除，各次扣除仍在原定回合结束恢复。它们不跳过普通攻击，不因普攻落空、被闪避或改道到本体而免除自身的发作；伤害n等技能生成的额外普攻不会额外触发状态发作。技能伤害走圣盾等既有技能减伤管线，赋予法术可反弹，已经附着的状态发作不二次反弹。离场清除卡面状态和重伤临时 ATK 减少。

献祭不会吸取手牌、准备区卡牌或共享自身生命的分身。友方生命可以被抽至 0，随后正常触发死亡、群体爆裂、不死/复活；先按实际吸取量恢复献祭者，再处理离场。

当前尚有仅声明、未接入的 trait：例如 **免疫** 已保留卡面和状态标记，但当前 `Resolver.damage` 尚无技能伤害拦截分支。其余图鉴中标注“未实现 / 待确认”的词条不赋予臆测机制。本表记录当前 3D 功能，旧版来源核查另见 [SKILL_COVERAGE.md](SKILL_COVERAGE.md)，近期新增机制见 [TRAIT_EXPANSION.md](TRAIT_EXPANSION.md)。


## 10. 离场状态重置与无目标技能（2026-10-09）

- 对敌方卡牌施放的攻击技能，无有效敌方在场卡时跳过，不生成技能动画、不回落到施法者自己。
  群体爆裂同样不在空场时改打本体；普通空槽攻击及明确直击本体的远射、攻城、贯穿仍按原规则生效。
- 卡牌进入弃牌堆后，HP/生命上限/ATK/CD 恢复卡牌模板基础值，清除祝福、诅咒、重伤减攻、
  赋予闪避、攻击后状态、不屈、狂暴缓存与已行动等本次战斗状态，并刷新一次性标记。
- 还魂回手或重新从牌堆抽取也统一执行干净初始化；不携带上一次在场的增减益。
  不死/直接复活同样恢复基础属性和临时状态；直接复活的已使用标记仍保留，以维持一次生命周期内只复活一次。
  真正进入弃牌堆并被取回后开始新生命周期，复活资格恢复。
- 从共享分身组回收/返场的主卡分离为独立新生命周期，不继续连接已经死亡的分身。
  离场动画使用死亡当时的冻结数值，重置数值通过规则事件同步到后续卡牌显示。
- 普通悬停抬升在移出、交互关闭、换区或拖动时清除；原生飞行单位的在场悬浮高度仍保留。
