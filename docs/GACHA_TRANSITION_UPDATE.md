# 抽卡连续衔接

主界面、抽卡演出与完成页共用持续存在的 Canvas、相机和完整背景板模型。主界面视角注视图片中央，预览卡保持原版设计坐标的等比位置；背景板、木框、金白虚空从进入页面时就存在。

正常流程：
1. 经济事务成功后，等待本轮纹理就绪；主界面的标题、卡池列表、资源与操作组件向周围移出，展示卡同步退场。
2. 镜头保持出发时的方向，缓慢拉远。
3. 单抽一道、十连十道实际稀有度颜色光柱与背面卡牌，按顺序从各自槽位上方下落；落点亮起圆环，卡牌靠近背景板。
4. 全部背面卡完成落位后，镜头逐渐拉近，再严格逐张翻开。最稀有的一张沿用推近聚焦、停留与回到全景的演出。
5. 完成页保留实体卡预览与离开／继续抽卡。继续抽卡让旧结果组件及旧实体卡先退场，再从当前相机位置走同一套衔接。

跳过模式直接达到同一批实体卡的终态，不补发过期光柱或揭晓爆点。测试资源按钮及底部概率横排保留。背景板与画布不会在各阶段或再次抽卡时重建，相机配置对象保持稳定。

验证：类型检查、生产静态构建通过；gachaTransition、choreography、gachaBoard、gachaCompletion、gachaMenu、gachaRevealStyle 共 51 项测试通过。包括阶段顺序、全部背面落位后才翻面、顺序翻牌不重叠、当前相机方向衔接、光柱生命周期、持续舞台及再次扣款流程。按照用户要求未启动实例、未截图检查。
