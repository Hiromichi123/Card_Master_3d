# 本地登录与账号存档

当前登录系统是离线浏览器本地账号。账号与游戏进度保存在当前站点的 IndexedDB，不请求远端认证服务器，不跨设备同步，不自动恢复登录会话。

## 账号

- 初始账号与密码均为 `admin`，首次使用时写入本地账号库。
- 用户名为 2–24 个中文、字母、数字、下划线、连字符或英文点。账号名经过 NFKC 规范化及首尾空格清理，比较时忽略大小写。
- 密码为 4–128 个字符，保留所有空格。密码使用 Web Crypto 的 PBKDF2 / SHA-256、600,000 次迭代、独立随机 128 位盐派生为 256 位摘要；不保存明文密码。
- 注册在账号写入事务完成后才显示成功。重复用户名通过 IndexedDB 唯一主键约束拦截，多标签页同时注册也不会覆盖账号。
- 密码校验需要 localhost 或 HTTPS 等支持 Web Crypto 的环境。存储不可用、配额不足、账号数据损坏等会显示错误，不伪装为注册或登录成功。

## 存档

- `admin` 继续使用原来的 `card-master-3d` 数据库，因此已有收藏、卡组、货币及设置保留。
- 新注册的账号拥有随机账号 ID，使用 `card-master-3d:account:<账号 ID>` 独立存档库；初始内容沿用当前游戏的新存档设定。
- 同一账号的重复请求共享存档实例和加载中的 Promise；打开失败会清理缓存，加载失败的实例在下次请求时重新建立。
- 登录路径要求真实持久化存储。存档库无法打开时停留在登录界面并报告错误，不降级到会在刷新后丢失的内存存档。
- 重置游戏存档只作用于当前账号的游戏数据，账号密码记录位于独立库中。

## 接口与边界

`src/services/auth/accounts.ts` 导出 `LoginAccount`、`authenticateAccount(username, password)`、`registerAccount(username, password)`；后两者返回 `Promise<LoginAccount>`，失败抛出中文 `Error`。注册返回成功账号信息，但不创建登录会话。

`getProfileStore(accountId = 'admin')` 返回对应账号的 `ProfileStore`。调用方必须继续等待 `store.load()` 并检查状态为 `ready` 后再展示游戏。

本地账号用于同一浏览器内区分玩家与进度，不构成联网身份验证。能修改浏览器存储或本地代码的人也能改动账号和存档；清除站点数据、切换浏览器或更换站点地址不会保留这些本地账号。当前无联网注册、账号找回或云存档。

按当前开发要求，本次未启动实例、运行构建或测试。

## 开场与登录操作

1. 黑色星空中播放金色 `Card Master 3D` 标题，约 2 秒后标题淡出，相机从约 37 单位高处约 2.13 秒下坠（下坠距离保持，速度提高 50%）到巨型圆形标准盘面上方；减少动态时放慢下坠。
2. 镜头真实沿盘面低空持续前进，从 A / A+ / S / S+ / SS / SS+ / SSS 卡牌中按稀有度交错抽取最多 32 种不同插画，空盘面在镜头落稳后由共享队列逐张落卡，约每 2.2–2.6 秒生成一张，从近处向前推进；横向远景改为独立的雾中显现卡带，不再参与下落队列。新落点不得位于已有卡牌与镜头之间，前方 64 单位之外不提前生成。卡牌从视野上方自由落下并倾斜插入盘面。每圈更换卡牌排列，低 / 中 / 高画质分别使用 28 / 40 / 48 个循环卡位；远景卡牌填充地平线前方的盘面。下落由独立时间与重力控制，速度较上一版提高 50%（耗时除以 1.5），减少动态时放缓而不直接落地。盘面在雾外按完整双色行补充，卡牌通过镜头后重新在远方落下；相机与场景共同重定位，循环衔接。盘面为半径 180 的圆形厚木板，外围两层灰黑云雾覆盖圆周与盘外，背景及距离雾采用同色过渡；左右横向远处另有直接从雾中显现的卡牌带，只使用 thumbnail 和粗糙普通材质，无全息、光晕、下落动画或投影。盘面压暗，地平线十字光晕增强，卡牌向地面投射柔化阴影，投影光源覆盖当前巡游区域。
3. 巡游至少 5 秒、展示资源完成准备后，底部出现呼吸金字「点击任意位置开始游戏」。也支持 Enter / 空格。
4. 点击后中央金边账号框向上浮现。默认填写 `admin / admin`；两个按钮分别登录、注册。注册成功后点击登录，登录错误直接在框内提示。
5. 验证与账号存档加载完成后，提前挂载真实大厅并保持不可操作。认证成功即停止其它落卡，未落地卡牌停止下落并淡出，已落地卡牌保留。大厅准备完成后，登录框退场，前方固定 44 单位处只落下一张中央卡背，下落速度同样提高 50%，插入地面后触发金色扩散环、柔光底座与卡背边缘照明，再翻面；认证后先维持巡游，中央卡背出现时相机从原速度平滑加速（加速系数提高至 0.13），持续到大厅完全展开，期间不停顿。正面只显示提前渲染大厅的一部分裁剪，不使用其它卡牌插画；从翻面正面朝向镜头时开始，以实体卡牌投影边缘裁剪大厅，开口随着靠近扩展到全屏后恢复大厅交互。

开场时间独立于战斗演出速度；后台标签页暂停推进。系统减少动态设置降低巡游与转场速度、冻结装饰粒子，不再直接冻结整个巡游；WebGL 不可用时保留星空与可操作的账号表单。刷新页面重新经过登录，不保存已验证会话。

## 维护位置

- `src/scenes/LoginScene.tsx`：表单、输入与错误状态、开场提示，以及图形异常的后备入口。
- `src/rendering/login/`：镜头编排、循环盘面与卡牌、反光材质、星空、地平线光晕和翻卡投影。
- `src/ui/login.css`：金色标题、金边流动面板、提示呼吸、表单升起和大厅裁剪层；按钮沿用公共金边倒角组件。
- `src/services/preloadHub.ts`：开场期间预加载大厅背景与海报，不阻塞失败的可选海报。
- `src/app/App.tsx`：账号与存档门禁、设置加载、真实大厅预挂载和最终交互切换。

本次仅改源码与文档，未运行实例、测试、构建、类型检查或截图；视觉效果由玩家运行查看。

大厅标题后缀自动显示当前版本；顶部 admin 导航栏默认收起，展开后可使用 +50000 金币 / 水晶测试资源。该栏目前为开发工具栏名称，不代表新增账号权限系统。
