# Trait 功能对照表

更新：2026-10-08。按当前 3D 版本整理，同类功能合并。`n` 表示卡面上的数值；“对位”指双方战斗区同下标槽位，“本体”指玩家生命。

除特别说明外，主动攻击技能在该卡攻击前结算，随后仍进行普通攻击。技能伤害不会因为目标飞行而转移到本体；剑舞、献祭、坍缩返伤与直接击杀使用独立扣血/离场路径。不屈可暂缓这些扣血造成的首次死亡，到期后再正常离场。献祭和传送在自身回合的部署结束后、整排攻击前，每张在场卡触发一次。

| Trait | 功能 |
| --- | --- |
| 火球n / 冰封n / 闪电n / 炮击n | 对随机敌方战斗单位造成 n 点技能伤害，分别使用火、冰、雷和炮击特效。冰封目前不额外冻结或跳过回合。 |
| 群体火球n / 群体冰封n / 群体闪电n / 群体爆破n | 对敌方全部战斗单位各造成 n 点技能伤害。 |
| 斩击n | 对当前对位造成 n 点技能伤害，使用两道交叉弧斩；对位为空时跳过。 |
| 群体斩击n | 对敌方全部战斗单位各造成 n 点技能伤害，各播放双弧斩击；兼容“群体斩n击”写法。 |
| 剑舞n / 群体剑舞n | 对当前对位 / 敌方全体各直接扣除 n HP，无视飞行、防御、闪避、免疫、圣盾和法术反弹。多段多方向圆弧刀光只表现一次 n 点扣血。 |
| 溅射 | 普攻命中对位时，对位仍受正常普攻，其相邻左右槽各受到 floor(原始 ATK / 2) 点普攻伤害；不向空相邻槽发起额外攻击，边缘只处理存在的一侧。相邻伤害分别走飞行、防御、圣盾、闪避和受击反击，不重复前冲或触发攻击者的攻击后技能。 |
| 群体延迟n | 对敌方全部等待区（准备区）卡牌增加 n 点 CD，不影响手牌或战斗区。 |
| 严霜n / 燃烧n / 剧毒n / 流血n | 持有者受到敌方普攻后，将相应状态赋予攻击者，即使被防御或闪避减至 0 也可赋予；持有者须仍在场可行动。新状态不在赋予它的同一次攻击中触发，从受赋予卡的下一次主动普攻后造成 n 技能伤害。分别使用 Frost Lance 白冰下雪、分支熔岩裂缝与红黄上升火星、Storm Lance 连续绿色烟雾注入条、受伤深红遮罩血滴；发作时卡面薄冰块飞散、火焰半球扩散与粒子四散、毒雾爆发或深红斩击。严霜抵达卡面后分三批随机、可重叠地升起较粗、较低且较实的冰冠，长短与倾斜各异，限制在卡面内，白霜为原始版本的 70%；燃烧裂隙仅由卡面层展开一次，范围扩大至宽、高约 92%，分叉长短、朝向和位置不规则，持续呼吸发光。 |
| 重伤n | 赋予时机和一回合期限同上；贴卡面且清晰的深红受伤法阵、深暗红遮罩，无流血粒子；发作使用与严霜同样的卡面掩膜开裂、碎片飞散，改为深红色。受赋予卡下一次主动普攻后 ATK 减少 n，下限为 0，到期或离场时加回实际减少量，保留其它增益与减益。 |
| 毒雾n | 攻击前选随机敌方，绿色无实体毒气团沿火球抛物线落到卡面爆发，造成随机 1–n 点技能伤害，并给仍存活的目标赋予剧毒n；可被法术反弹。 |
| 伤害n / 群体伤害n | 对随机敌方 / 敌方全体分别进行一次 n 点普通攻击，遵循飞行、防御、圣盾、闪避和反击规则。 |
| 贯穿n | 独立对敌方本体造成 n 点伤害，金色直线光尾，无爆炸；不改变普通攻击的目标。 |
| 群体贯穿n | 战场五个对位槽各播放一条平行金色贯穿光线，末端延伸穿过本体落点；每条独立对敌方本体造成 n 点伤害，合计至多 5n，不伤害战斗区卡牌。 |
| 临点坍缩 | 普攻真正命中对位卡时，若减伤、闪避结算后的伤害超过对位命中前剩余 HP，将超出的部分直接返还给自己，自己卡面播放红色双弧斩击。打空槽、远射或飞行改道不触发。 |
| 不屈 | 首次 HP 归零后暂不离场，继续普攻、施法、占位与接受目标选择，到下一个自身回合结束后再进入死亡离场流程。持续期间卡面覆盖鲜红外溢边缘、较暗中心的遮罩；重复致命伤害不刷新期限，恢复 HP 也不取消到期离场。 |
| 远射 | 使普通攻击越过对位卡牌直接命中敌方本体，小爆炸并留下长直线烟雾拖尾。 |
| 即死n | 随机敌方战斗单位 HP 立即清零并触发死亡处理，使用黑色诅咒。n 为保留的等级参数，不改变必杀结果。 |
| 斩杀 | 己方回合攻击前，如果对位当前 HP 严格低于自身当前 HP，直接击杀对位并使其离场，使用深红剑舞。对位为空、同血或更高血量时跳过；兼容旧卡面“斩杀3”，数字不作为固定血量阈值。 |
| 自毁 | 上场立即完成自身技能与一次有效攻击，然后 HP 清零离场；一次性卡牌在场不显示 HP、ATK。 |
| 死亡爆裂n / 爆裂n / 爆裂 | 死亡离场时原地爆裂，并对敌方全部战斗单位各触发炮击；未带数字时默认 2 点伤害，敌方战斗区为空时命中本体。 |
| 隐匿 | 每次进入战斗区后，规避真正命中自己的第一次普通攻击，包括伤害n和溅射的普通命中。技能伤害、真伤、即死和直击本体不消耗隐匿；规避成功后本次减伤/闪避不再重复抽取。每个分身/复制实例分别记一次。 |
| 先攻 | 无视原槽位先于己方普通单位行动；多个先攻仍按原槽位从前到后。只改变攻击调度，不交换槽位或对位。 |
| 吞噬 | 攻击前清空敵方全部弃牌；牌堆、手牌和场上单位不受影响，被吞噬的牌不能再被还魂回收。空弃牌堆时跳过。 |
| 至高之作 | 上场后在己方第一个空战斗槽召唤一张满血、独立状态的 A+_006 蒸汽艺术（ATK 2 / HP 6，飞行、火球1），立即在场，不消耗牌组或藏品，也不再次等待原 CD 5。没有空位时跳过。 |
| 先锋 | 在场且 HP>0 时优先替队友承受能够命中的普通攻击，包括伤害n和溅射；多个先锋按槽位顺序选择一张，先锋自己受攻不再相互转移。实际承受者正常触发隐匿、减伤、闪避和反击；不替本体承受远射/攻城、空槽攻击或飞行改道，也不接法术或真伤。无法被当前地面攻击命中的飞行先锋不拦截。 |
| 必杀n | 攻击前以 20%−10%×0.5^(n−1) 的概率直接击杀当前对位：1级10%、2级15%、3级17.5%，上限20%。成功时播放黑色即死动画，失败时不播放；不属于来袭法术，不被法术反弹或先锋拦截，仍保留不屈等正常离场机制。 |
| 对空 | 自身普攻（包括伤害n产生的普通命中）能够攻击飞行单位，正常触发防御、圣盾、闪避与反击；不会因此变成飞行单位。无额外动画。 |
| 群体禁飞 | 持有者在场且未被对位沉默时，持续压制敌方全部在场飞行单位，使其落地并可被地面普攻。包含后续上场的飞行卡；所有光环持有者离场或被沉默后，原飞行卡恢复飞行。属性光环不作为法术反弹，无额外施法动画。 |
| 攻城 | 自身普攻越过对位卡直接打敌方本体，保留普通卡牌前冲，不发射弹体、爆炸或烟雾；不触发被越过卡的受击反击和溅射。与远射同在时优先使用攻城表现，无额外技能动画。 |
| 飞行 | 未被群体禁飞压制时，不受不具对空的地面单位普攻；地面普攻穿过自己，攻击己方本体。飞行单位的普攻可以命中飞行单位，技能伤害仍可命中。 |
| 防御n | 每次受普通攻击时减免 n 点伤害，减免量会被破甲抵消；不减免技能伤害。 |
| 圣盾n | 每次受到普通攻击或普通技能伤害时减免 n 点，不受破甲影响；不挡真伤、献祭或直接击杀。 |
| 破甲n | 对位有防御时，为本次普通攻击提供 n 点破甲，抵消相应防御减伤。 |
| 闪避n | 按等级概率闪避普通攻击：1 / 2 / 3 级分别为 30% / 60% / 75%，继续升级渐近 90%。 |
| 闪避赋予n | 把闪避n赋予随机友方，优先其它友方，持续至该卡离场；重复赋予与原有闪避取最高等级，使用金色破甲动画。 |
| 法术反弹 | 持有者在场时保护己方，将敌方来袭法术整次返回施法方，包括群体法术和传送；一次法术只反射一次。普通攻击、远射、贯穿、剑舞与斩杀不反弹。 |
| 献祭n | 每个自身回合，从其它在场友方总共抽取至多 n 点生命恢复自身。随机选取来源，不足时继续取其它友方；按实际抽取量回血，达到生命上限立即停止。没有可用友方或自身满血时跳过，使用吸血动画。 |
| 传送 | 每个自身回合随机打乱敌方战斗区卡牌顺序，更新对位关系；保持已有空槽位置，少于两张存活敌方时跳过。兼容旧卡面“传送1”。 |
| 治愈n / 治疗n | 治疗随机一张受伤友方 n HP，优先其它受伤友方，最多恢复到生命上限；没有受伤友方时跳过。 |
| 群体治愈n | 治疗全部受伤友方各 n HP，最多恢复到各自生命上限。 |
| 恢复n | 恢复自身 n HP，最多到生命上限，满血时跳过。 |
| 吸血n | 一次攻击确实造成伤害后，恢复自身固定 n HP，最多到生命上限。 |
| 祝福n / 群体祝福n | 随机友方（优先其它友方）/ 全部友方的 ATK 与当前 HP 各增加 n；当前实现允许 HP 超过基础上限。 |
| 振奋n / 群体振奋n | 上场时，随机友方 / 全部友方的 ATK 增加 n，不增加 HP。 |
| 诅咒n | 使当前对位的 ATK 降低 n，最低为 0，使用紫色束缚动画。 |
| 受伤n | 攻击后自身受到 n 点自伤，可以导致死亡；使用红色低矮束缚动画。 |
| 狂暴 / 狂暴1 | 当前 ATK = 其它增减益作用后的基础 ATK + max(0, 生命上限 − 当前 HP)，最低为 0。受到伤害立即加攻，回血立即回落；不再主动自伤，也不永久累计加攻，无额外动画。共享分身只维护一份加成，独立复制保留独立数值。 |
| 反击n | 受到普通攻击且确实损失生命后，对攻击者造成 n 点技能伤害。 |
| 沉默 | 压制当前对位卡的主动技能与受击技能；位置改变后重新判定，死亡系 trait 仍按原有离场规则执行。 |
| 抽卡n | 从己方牌堆抽 n 张到手牌；剩余牌堆不足 n 张时不触发。 |
| 还魂n | 从己方弃牌堆取回 n 张到手牌，重置不死/复活标记；不足 n 张时不触发。 |
| 加速n | 己方最左侧已占用准备槽的 CD 减少 n，最低为 0。 |
| 延迟n / 延时n | 敌方最左侧已占用准备槽的 CD 增加 n。 |
| 分身 | 上场时在空友方战斗槽生成分身，共享 HP、ATK 等状态；同组生命耗尽时整组离场。 |
| 复制 | 攻击前在空友方战斗槽生成独立复制体；己方每回合最多一次。 |
| 不死 | 死亡后恢复生命并返回手牌，可以再次上场，没有单次消耗限制。 |
| 复活 | 死亡后恢复生命并返回空准备槽，重新冷却；每次生命周期只能触发一次，没有空准备槽时失败。 |

五种攻击后状态各自独立，持续到受赋予卡下一个自身回合结束；同类重复赋予取较高 n 并刷新一回合期限，异类可以共存；刷新重伤卡面状态不延长已经发生的临时 ATK 扣除，各次扣除仍在原定回合结束恢复。它们不跳过普通攻击，不因普攻落空、被闪避或改道到本体而免除自身的发作；伤害n等技能生成的额外普攻不会额外触发状态发作。技能伤害走圣盾等既有技能减伤管线，赋予法术可反弹，已经附着的状态发作不二次反弹。离场清除卡面状态和重伤临时 ATK 减少。

献祭不会吸取手牌、准备区卡牌或共享自身生命的分身。友方生命可以被抽至 0，随后正常触发死亡、死亡爆裂、不死/复活；先按实际吸取量恢复献祭者，再处理离场。

当前尚有仅声明、未接入的 trait：例如 **免疫** 已保留卡面和状态标记，但当前 `Resolver.damage` 尚无技能伤害拦截分支。其余图鉴中标注“未实现 / 待确认”的词条不赋予臆测机制。本表记录当前 3D 功能，旧版来源核查另见 [SKILL_COVERAGE.md](SKILL_COVERAGE.md)，近期新增机制见 [TRAIT_EXPANSION.md](TRAIT_EXPANSION.md)。
